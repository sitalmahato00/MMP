Native-like academic PWA

MMP mobile app shell built for thumb reach, dense data, scoped feeds, and dark mode.

This mockup shows the full direction for Public, Admin, Teacher, Student, Parent, and the shared notification center. It intentionally avoids desktop sidebars, oversized cards, and noisy dashboards. Every list stays compact, readable, and role-filtered.

What we reject

Desktop navigation on mobile, cardified tables, mixed-scope notices, long forms without sectioning, and generic web layouts that do not feel app-native.

Navigation model

Fixed top bar + fixed bottom navigation for every role. Notification access is global. Primary create actions live in a FAB or bottom action bar.

List behavior

Sticky list headers, 14px to 15px text, 48px to 56px rows, 3 to 4 visible columns, ellipsis for overflow, and expandable secondary metadata.

Notification engine

Real-time in-app updates plus service-worker push delivery. Results and exams are high priority. Resources are silent or grouped.

Compact table formula

14px to 15px row text, 8px to 10px padding, 48px to 56px row height, sticky headers, ellipsis for long titles, and actions grouped on the trailing edge.

Dark mode behavior

The app defaults to system theme, stores user preference, and keeps brand accents warm and readable in both modes instead of inverting into muddy grayscale.

Filtering principle

Role, department, program, semester, and child context must be resolved before any list renders. No broadening OR rules after scope checks.

Notification delivery

Results and exams are urgent. Notices are medium priority. Resources are grouped or silent. Every row deep-links directly into the destination screen.
